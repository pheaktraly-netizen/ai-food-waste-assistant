# FoodSaver: AI Food Waste Reduction Assistant

A UI/UX prototype for COMP826 Mobile Systems Development, Milestone 2. FoodSaver helps users track food in their kitchen, see what is about to expire, and get recipe ideas that use those ingredients before they go to waste.

**Role:** UI/UX Designer
**Author:** Pheaktra Ly (25302591)

## How to view the prototype

1. Open the Figma link above. No Figma account is needed.
2. Click the **Play (▶)** button at the top right to start the click-through.
3. The prototype starts on the Login screen. Click **Log In** to reach Home.
4. From Home, tap Inventory, Recipes, Shopping List, Waste Stats or Profile.
5. Use the back arrow at the top of each screen to go back.

## Screens

Login, Register, Forgot Password, Home, Inventory, Item Detail, Add Food (manual and barcode), Recipes, Shopping List, Waste Statistics, Profile.

## Known limitations

- This is a design prototype only. There is no backend, database or working barcode scanner, and all data shown is example content.
- The "Log wasted item" button on Waste Statistics is not linked to a screen yet.
